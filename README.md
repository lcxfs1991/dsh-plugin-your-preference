# 个性化管理（Personal Preference）

DeepSeek Harness（DSH）插件：在 Web 界面中查看你的插件与技能清单，并通过一个 ZIP 文件把它们导出/导入，方便在多台机器之间迁移个性化配置。

[English README](./README.en.md)

## 功能介绍

- **清单查看**：在左侧侧边栏底部的「个性化管理」入口打开对话框，集中查看 DSH 版本、已启用的默认插件、外部安装的插件、已安装的技能，以及 `~/.dsh/skills` 下的用户技能。
- **一键导出**：点击「导出 ZIP」，下载 `dsh-preference.zip`。其中包含 `manifest.yaml`（插件与技能的清单信息）以及 `~/.dsh/skills` 下所有用户技能文件（保留原始目录结构）。
- **安全导入**：点击「导入 ZIP」选择之前导出的压缩包，插件会被安装/启用，技能文件会被复制到 `~/.dsh/skills`；**已有文件不会被覆盖**，冲突会逐条提示。

### 实现方式与隐私说明

这个插件只做「读取清单 + 打包技能文件」两件事。浏览器端只向本地 Harness 的 `/api/dsh-pref/inventory`、`/api/dsh-pref/export`、`/api/dsh-pref/import` 三个接口发起请求，这些接口注册在 Host Connection 的共享 `/api` 通道上，与 DSH 其他 API 使用同一套**本机所有者身份认证**，只有你当前浏览器连接的本地 Harness 能访问，不会对外暴露。清单数据来自「插件」页面所用的同一批 Host 服务（`pluginManager`、`skills`）以及对 `~/.dsh/skills` 的直接扫描；导出的内容只有插件/技能元数据和技能文件本身。插件**不会读取或导出你的对话记录、API Key、凭据、环境变量或任何配置密钥**，不访问第三方服务，也没有任何遥测上报；ZIP 与 YAML 的处理全部由 Node 内置模块在插件内完成，不依赖外部包。

导入侧同样做了防护：请求体上限 256 MB；ZIP 仅支持标准存储/deflate 条目并校验大小；YAML 解析器拒绝 `__proto__` 等危险键名；技能文件路径会拒绝绝对路径与 `..` 目录穿越；写入时使用 `wx` 模式，遇到已存在的文件直接跳过并报告，绝不覆盖。

## 安装

插件是一个本地 bundle，包名 `@local/dsh-plugin-your-preference`，要求 Node.js ≥ 24.9.0。

- **方式一（推荐）**：在 DSH Web 界面中打开 **插件（Plugins）→ 添加插件（Add plugin）**，选择本插件所在的目录。
- **方式二**：在具备 `plugin_manager` 工具的 DSH 会话中，直接说明需要安装此插件，并提供本目录的绝对路径（会以 `install_bundle` 方式安装）。

安装并启用后刷新页面，左侧侧边栏底部会出现「个性化管理」入口。

## 使用

1. **打开对话框**：点击左侧侧边栏底部的「个性化管理」按钮。首次打开会自动读取清单，显示 DeepSeek Harness 版本以及四组信息（默认插件、外部插件、已安装技能、用户技能）。读取失败时可点「重试」。
2. **导出**：在对话框中点击「导出 ZIP」。浏览器会下载 `dsh-preference.zip`，可将其保存到新机器备用。
3. **导入**：在新机器的 DSH 中打开同一对话框，点击「导入 ZIP」，选择该压缩包。完成后会提示插件变更数量、复制的技能文件数量；若存在冲突或错误，会在结果区域逐条列出。
4. **校验**：导入后清单会自动重新加载。如需手动确认，重新打开对话框即可。

> 对话框支持 `Esc` 关闭与 `Tab` 焦点循环；点击遮罩层空白处也可关闭。界面文案随 DSH 的语言设置切换（内置中英文）。

## 导出包内容

```
dsh-preference.zip
├── manifest.yaml          # 清单：schemaVersion、产品版本、插件列表、技能列表
└── skills/                # ~/.dsh/skills 下的全部用户技能文件（按原目录结构）
```

- `manifest.yaml` 使用插件自带的精简 YAML 读写实现，schema 版本为 `2`，仅用于本插件导出/导入。
- 目录式技能（`SKILL.md` + 资源文件）保留其技能目录名；扁平技能（单个 `.md` 文件）直接放在 `skills/` 下，避免文件名冲突。

## 常见问题

- **导入后技能没有立即生效？** 技能文件系统会自动监听 `~/.dsh/skills` 并使目录失效，无需手动刷新；如界面未更新，可重开对话框或刷新页面。
- **提示「已存在，未覆盖」？** 这是预期的安全行为：目标文件已存在时会保留原文件，跳过冲突项。如需用新版本替换，请先手动删除旧文件再导入。
- **导出的 ZIP 里有什么敏感信息吗？** 没有。只包含插件/技能的名称、描述等清单元数据，以及 `~/.dsh/skills` 下的技能文件；不含对话、密钥、凭据或环境变量。分享或保存 ZIP 前仍可按个人习惯检查其内容。

```
cordis.patch.yml  # bundle 加载补丁
locale/           # 插件展示元信息（中英文）
icon.svg          # 插件图标
package.json      # 包与 DSH bundle 声明
```
